## Dependency compatibility

Next.js and its ESLint configuration are aligned at 16.3.8. Prisma CLI, client and PostgreSQL adapter remain aligned at 7.8.0. Auth.js is 5.0.0-beta.32 with core 0.41.3. Vitest/coverage are aligned at 4.1.11 and Vite resolves to a patched 7.3.x release.

Nodemailer 10.1.1 is newer than Auth.js's declared optional peer range. Centavo uses its own `createTransport`/`sendMail` SMTP implementation and its own Resend delivery function. The peer allowance is explicit, and the actual local SMTP sign-in flow passed with these versions. SMTP type declarations remain at the latest available 8.0.x version; TypeScript passes.

### Development-only braces mitigation

The registry reports GHSA-vfj7-8cjw-p6xm for all published `braces` versions through 3.0.3 and provides no fixed release. The dependency is used by development glob tooling, not the production app.

`patches/braces@3.0.3.patch`, recorded through pnpm's patched dependencies, limits parse nesting and recursive AST walkers to 64 levels. Regression tests reject deeply nested brace/parenthesis inputs and externally supplied deep ASTs while preserving ordinary glob expansion. Frozen installs apply the patch reproducibly.

The unfiltered full dependency audit still reports this single advisory because it cannot account for a local source patch. No advisories are suppressed. Replace the patch with an upstream fixed version when one becomes available.

## Operational semantics

Telegram processing is retried by Telegram when the handler returns 503 or a worker exits before acknowledging. A crashed worker's lease becomes claimable after ten minutes. Expense mutations and their receipts are atomic. Telegram's external send API cannot participate in the database transaction: a reply may repeat if delivery succeeds immediately before a connection/worker failure, while the recorded expense mutation is reused.
